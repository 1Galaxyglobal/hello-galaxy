# 一个初学者的积累
# 📁 个人学习资源与项目仓库

本仓库主要用于整理个人的学习资料、Python 实战项目代码以及相关的工具资源。内容涵盖机器学习、PDF 自动化处理以及 Minecraft 相关模组/工具。

---

## 📂 目录结构说明

### 1. Books (学习资料)
存放机器学习及相关领域的经典书籍和参考资料。
- `pumpkin_book.pdf`：南瓜书（对经典机器学习公式的详细推导）。
- `机器学习实战.pdf`：机器学习实战书籍电子版。

### 2. MC (Minecraft 相关资源)
存放 Minecraft 相关的模组、工具或数据包。
- `PCL 正式版 2.12.7.3`：PCL 启动器相关文件。
- `Mechanomania-航空学-0.0.6 (1)...`：航空学相关模组。
- `PCL 正式版 2.12.7.3.zip`：PCL 启动器压缩包。

### 3. PDFEditor_Package (PDF 编辑工具包)
基于 Python 编写的 PDF 编辑脚本集合，用于自动化处理 PDF 文件。
- `pdf_editor.py`：基础版 PDF 编辑器。
- `pdf_editor_plus.py`：增强版 PDF 编辑器。
- `pdf_editor_pro.py`：专业版 PDF 编辑器。
- `pdf_editor_suv.py`：SUV 版（可能是特定功能版）PDF 编辑器。

### 4. machinelearn (机器学习实战代码)
包含丰富的机器学习算法实战案例，基于 Python 实现。主要涵盖回归、分类、聚类、集成学习及模型评估等内容。

#### 📁 文件夹
- `__pycache__`：Python 缓存文件。
- `data`：存放数据集文件。
- `model`：存放训练好的模型文件。

#### 🐍 核心代码文件
- **回归算法**：
  - `线性回归波士顿房价预测.py`：使用线性回归预测房价。
  - `线性回归和决策树对比.py`：对比线性回归与决策树的性能。
  
- **分类算法**：
  - `KNN01.py`：K 近邻算法基础实践。
  - `决策树泰坦尼克号.py`：使用决策树进行泰坦尼克号生存预测。
  - `朴素贝叶斯商品选择倾向.py`：基于朴素贝叶斯的商品倾向预测。
  - `逻辑回归电信客户流失.py`：电信客户流失预测。
  - `逻辑回归癌症预测.py`：基于逻辑回归的癌症预测。
  - `GBDT泰坦尼克案例.py`：使用 GBDT 处理泰坦尼克号数据集。
  - `XGboost红酒品质分类案例.py`：使用 XGBoost 进行红酒品质分类。

- **聚类算法**：
  - `聚类Kmeans.py`：K-Means 聚类算法实践。
  - `花的种类测试.py`：基于聚类的花卉分类测试。
  - `用户分群.py`：利用聚类算法进行用户分群。
  - `聚类算法评估指标.py`：聚类模型评估指标计算。

- **集成学习与模型优化**：
  - `集成学习：Bagging, Boosting.py`：集成学习基础概念与实现。
  - `集成学习Boosting AdaBoost葡萄酒.py`：使用 AdaBoost 处理葡萄酒数据集。
  - `L1L2正则化解决过拟合问题.py`：通过正则化手段解决过拟合。
  - `交叉验证网格搜索.py`：超参数调优与交叉验证。

- **评估与预处理**：
  - `混淆矩阵.py`：绘制并分析混淆矩阵。
  - `特征预处理归一化与标准化.py`：数据特征预处理操作。
  - `手写数字识别.py`：基于 sklearn 的手写数字识别。
